Tiq

Tiny source. Explicit intent. Compiled programs.

A small, statically typed, ahead-of-time compiled language for fast tools and services. No mandatory VM or GC — the default compiler emits C you can inspect, then builds a native executable.

// A recurrence can be the program:

// Mutation is a choice:
count <- 41

Why Tiq?

C11 bootstrappre-alpha v0.1MIT
  • Small syntax, useful combinations. Expression functions, recurrences, bracket loops.
  • Names are visible. No implicit i, x, it — you name every binder.
  • Mutation is explicit. = immutable, <- mutable, &mut at call sites.
  • Costs are understandable. Inspect emitted C, measure the real program.

Pre-alpha: syntax and ABI can change. Start with small programs, not production services.

One loop shape, several jobs

Like Hylo's “Achievements” section, this is what Tiq can already do today — every snippet below is a complete program for the default C backend.

Recurrences, not machinery

factorial = [1, ... (x; i) -> x * i]
powers base -> [1, ... (x) -> x * base]

print(factorial[5])  // 120
print(powers(2)[10]) // 1024

Seeds + named previous terms + rule. O(k) steps, O(1) state per access.

Bracket loops

total <- 0
[n <- 1..11] {
    n % 2 == 0 ? { skip }
    total += n
}
print(total) // 25

Ranges exclude upper bound. Multiple binders = nested loops. break/skip target innermost.

Failure in the return value

half n: i64 : Result[i64, i64] ->
    n % 2 == 0 ? ok(n / 2) : err(1)

print(half_plus_one(40) ?? -1) // 21
print(half_plus_one(41) ?? -1) // -1

?expr propagates, ?? falls back. No exceptions.

Syntax at a glance

Familiar operators keep familiar meanings: + - * / %, == != < <= > >=, && || !, & | ^ << >>.

FormMeaning
name = valueImmutable binding
name <- valueMutable binding / reassignment, never shadowing
f x -> exprFunction with inferred types
f x: i64 : i64 -> x + 1Typed function
c ? a : bChoose a value (no if/else keywords)
[i <- 0..n] { ... }Iterate half-open range
[cond] { ... }Repeat while true
[1, ... (x) -> x * 2]Recurrence generator
?r / r ?? dPropagate failure / fallback
xs[a..b]Non-owning slice (byte offsets for strings)

Benchmarks, honestly

Small programs and fast builds are goals, not blanket claims. Reproduce with make benchmark-compare (needs python3, cc, go, rustc).

Runtime

Tiq within 5–26% of optimized C, competitive with Rust, 5–30% faster than Go, 20–30× faster than Python on five CPU-bound workloads.
