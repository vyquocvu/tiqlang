Getting started

git clone https://github.com/vyquocvu/tiqlang.git
cd tiqlang
make
./build/tiq run examples/fib.tiq

./build/tiq check examples/hello.tiq
./build/tiq emit-c examples/hello.tiq
./build/tiq build examples/hello.tiq -o build/hello
./build/hello

Prerequisites: make, C11 compiler (Clang/GCC), POSIX shell. Homebrew: brew tap vyquocvu/tiq && brew install tiq.

CLI reference

CommandWhat it does
tiq check file.tiqParse + type-check only, fail closed with located diagnostics
tiq run file.tiqCompile via C backend and run
tiq build file.tiq -o outBuild native executable (add -l/-L for C libs, --release for -O3)
tiq emit-c file.tiqPrint generated C11 to stdout
tiq emit-ir / dump-nativeInspect SSA IR / native assembly
tiq fmt / test / bench / init / lspDeveloper tools written in Tiq (see docs/CLI.md)

AreaCurrent scope
Default compilerISO C11 bootstrap; emits C, invokes host compiler
Self-hostingTiq-written compiler, three-stage bootstrap fixed-point test
Other backendsExperimental QBE native + wasm32-wasi; coverage differs
Toolsfmt test bench init cache lsp proxy router json under src/tiq/tools/
LimitsNo general closures, no bounded/predicate-sliced streams, no arbitrary generics, no full lifetime system
